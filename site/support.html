Back up your library

Everything is stored on your device, so export a backup regularly: Settings, then Export setlists. Keep the file somewhere safe. To restore, use Settings, then Import on any device. Importing adds setlists and never replaces what you already have.

Moving to a new phone

Export on the old phone, send the file to the new one, then import it in Settings.

The screen keeps sleeping

Check that "Keep screen awake" is on in Settings.

Scrolling is too fast

Open the snail control in Performance view, or lower the default auto-scroll speed in Settings. The speed can go as low as 1.
